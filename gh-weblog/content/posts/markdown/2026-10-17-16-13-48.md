You know how Hyper-V has an automatic checkpoint option, and how it's completely useless because what it actually does is "make sure there is at least one checkpoint", so the moment you have one, it'll do nothing? Why can't it just take an actual snapshot automatically every time you start up the VM, so that if you do something stupid that session, you just reset to the _latest_ snapshot?

So let's just set that up shall we? This is a repost of the answer I posted for this over on SupeUser:

Step one: we write a powershell script that tells Hyper-V to takes a snapshot for your VM.

```powershell
$VM = "YOUR_VM_NAME"

# Get the event properties
$Event = Get-WinEvent -LogName "Microsoft-Windows-Hyper-V-Worker-Admin" -MaxEvents 1
$EventVM = $Event.Properties[0].Value

# Is this about the correct VM?
if ($EventVM -ne $VM) { exit 1 }

# Start event for the correct VM: take a snapshot.
$now = Get-Date -Format "M/d/yyyy - h:mm:ss tt"
$snapshot = "Automatic Checkpoint - ${VM} - (${now})"
Checkpoint-VM -Name "${VM}" -SnapshotName "${snapshot}"
```

Step two: we run Event Viewer with admin rights, and look at the "Applications and Services Logs", specifically `Microsoft\Windows\Hyper-V-Worker\admin`. When we start a VM, we should see an event with id `18609`: "... properties were successfully initialized". This event fires as part of VM startup, but _before_ the VM boots, so that's when we want to take the snapshot. Right click the event and pick "Attach Task To This Event".

Give that a name and description, then hit next. The event trigger will already be filled in, so next again. As our action we'll start a program, specifically `powershell.exe` with the following arguments to load the script we just made: `-ExecutionPolicy Bypass -WindowStyle Hidden -File "...\your-script.ps1"`, then hit next, check the "open the properties dialog" option, and hit finish.

In the new task properties, we now need to make sure this will run "whether the user is logged in or not", with the "run with highest privileges" turned on. Hit "OK" and you're good to go.

Or, if you _really_ want to preserve the original automatic snapshot behaviour, i.e. "only take a snapshot if there aren't any yet", then update the snapshot script to check whether or not there's already a snapshot for your VM and if there is, exit early:

```powershell
...

# Are we snapshot-free?
if (Get-VMSnapshot -VMName $VM) { exit }

# Okay, *now* we can take a snapshot.
...
```
